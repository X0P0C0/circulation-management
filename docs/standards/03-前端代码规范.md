## 4. 编码规范

### 4.1 Vue 组件编写规范

```vue
<script setup lang="ts">
/**
 * 配件入库页面
 * 功能：扫码/手动输入条码，填写配件信息，提交入库
 */

// 1. 导入
import { ref, reactive, onMounted } from 'vue'
import { ElMessage } from 'element-plus'
import type { FormInstance, FormRules } from 'element-plus'
import { accessoryInbound } from '@/api/accessory'
import { listCategories } from '@/api/category'

// 2. 类型定义
interface InboundForm {
  barcode: string
  name: string
  spec: string
  categoryId: number | null
  unit: string
  remark: string
}

// 3. 响应式状态
const formRef = ref<FormInstance>()
const loading = ref(false)
const categoryList = ref<Category[]>([])
const form = reactive<InboundForm>({
  barcode: '',
  name: '',
  spec: '',
  categoryId: null,
  unit: '',
  remark: ''
})

// 4. 校验规则
const rules: FormRules = {
  barcode: [{ required: true, message: '请输入条码', trigger: 'blur' }],
  name: [{ required: true, message: '请输入配件名称', trigger: 'blur' }],
  categoryId: [{ required: true, message: '请选择分类', trigger: 'change' }]
}

// 5. 方法
const handleSubmit = async () => {
  await formRef.value?.validate()
  loading.value = true
  try {
    await accessoryInbound(form)
    ElMessage.success('入库成功')
    resetForm()
  } finally {
    loading.value = false
  }
}

const resetForm = () => {
  formRef.value?.resetFields()
}

// 6. 生命周期
onMounted(async () => {
  const { data } = await listCategories()
  categoryList.value = data
})
</script>

<template>
  <!-- 页面内容 -->
</template>

<style scoped lang="scss">
/* 组件样式 */
</style>
```

### 4.2 组件选项顺序

`<script setup>` 内部按以下顺序组织代码：

1. `import` 导入语句
2. 类型定义（`interface` / `type`）
3. `defineProps` / `defineEmits`
4. 响应式状态（`ref` / `reactive`）
5. 计算属性（`computed`）
6. 监听器（`watch`）
7. 方法函数
8. 生命周期钩子（`onMounted` 等）
9. `defineExpose`（如需要）

### 4.3 文件命名规则

| 类型 | 规则 | 示例 |
|------|------|------|
| 页面组件 | PascalCase / kebab-case | `TransferOut.vue` 或 `transfer-out.vue` |
| 公共组件 | PascalCase | `BarcodeScanner.vue` |
| API 文件 | camelCase | `accessory.ts` |
| Store 模块 | camelCase | `user.ts` |
| 工具函数 | camelCase | `request.ts` |
| 样式文件 | kebab-case | `element-override.scss` |

## 5. 请求封装规范

### 5.1 Axios 实例配置

```typescript
// utils/request.ts
import axios from 'axios'
import { getToken, removeToken } from './auth'
import { ElMessage } from 'element-plus'
import router from '@/router'

const service = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL, // 从环境变量读取
  timeout: 15000
})

// 请求拦截器：注入 Token
service.interceptors.request.use((config) => {
  const token = getToken()
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 响应拦截器：统一处理错误
service.interceptors.response.use(
  (response) => {
    const { code, message, data } = response.data
    if (code === 200) {
      return response.data
    }
    // 业务错误
    ElMessage.error(message || '请求失败')
    return Promise.reject(new Error(message))
  },
  (error) => {
    if (error.response?.status === 401) {
      removeToken()
      router.push('/login')
      ElMessage.error('登录已过期，请重新登录')
    } else {
      ElMessage.error(error.message || '网络异常')
    }
    return Promise.reject(error)
  }
)

export default service
```

### 5.2 API 文件编写规范

```typescript
// api/accessory.ts
import request from '@/utils/request'

/** 配件入库 */
export function accessoryInbound(data: {
  barcode: string
  name: string
  spec?: string
  categoryId: number
  unit?: string
  remark?: string
}) {
  return request.post('/api/accessory/inbound', data)
}

  return request.get(`/api/accessory/${barcode}`)
}
```

## 7. 状态管理规范

- 仅在**跨组件共享状态**时使用 Pinia，局部状态用 `ref/reactive`。
- Store 模块按业务域划分：`user.ts`（用户认证）、`app.ts`（应用配置）。
- Store 内部提供 `actions` 封装异步操作，不在组件中直接调用 API 后再 commit。

```typescript
// store/modules/user.ts
import { defineStore } from 'pinia'
import { login, logout } from '@/api/auth'
import { getToken, setToken, removeToken } from '@/utils/auth'

export const useUserStore = defineStore('user', {
  state: () => ({
    token: getToken() || '',
    username: ''
  }),
  actions: {
    async loginAction(loginForm: { username: string; password: string }) {
      const { data } = await login(loginForm)
      this.token = data.token
      this.username = data.username
      setToken(data.token)
    },
    async logoutAction() {
      await logout()
      this.token = ''
      this.username = ''
      removeToken()
    }
  }
})
```

## 8. 组件设计原则

| 原则 | 说明 |
|------|------|
| 单一职责 | 一个组件只做一件事 |
| Props 下传，Events 上传 | 父子组件通信标准模式 |
| 避免深度嵌套 | 组件层级不超过 3 层 |
| 公共组件提取 | 出现 2 次以上的 UI 模式提取为公共组件 |
| 组件文件不超过 300 行 | 超过则拆分为子组件 |
