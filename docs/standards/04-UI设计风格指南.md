# UI 设计风格指南

> 配件流转管理系统 | 视觉设计规范  
> 参考：vue-pure-admin 设计语言 + Element Plus 设计体系  
> 版本：V1.0 | 更新日期：2026-05-27

---

## 1. 设计理念

**关键词**：工整、克制、专业、高效

- **不追求炫酷**，追求信息密度和操作效率。
- **不追求个性化**，追求一致性和可预测性。
- **不堆砌动效**，仅在必要时使用微交互反馈。
- **留白有节奏**，间距遵循 4px 基准网格。

## 2. 色彩体系

| 用途 | 色值 | 变量 |

## 3. 字体规范

### 3.1 字体栈

```scss
$font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto,
  'Helvetica Neue', Arial, 'Noto Sans', 'PingFang SC', 'Microsoft YaHei',
  sans-serif;
```

### 3.2 字号层级

| 层级 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| H1 | 20px | 28px | 600 | 页面主标题 |
| H2 | 16px | 24px | 600 | 区块标题 |
| H3 | 14px | 22px | 600 | 卡片标题 |
| 正文 | 14px | 22px | 400 | 表单、表格内容 |
| 辅助 | 13px | 20px | 400 | 标签、提示文字 |
| 小字 | 12px | 18px | 400 | 次要信息、时间戳 |

### 3.3 对齐规则

- 表单标签：右对齐（Element Plus 默认）
- 表格内容：左对齐（数字列居中）
- 按钮文字：居中
- 页面标题：左对齐

## 4. 间距系统

基于 **4px 基准网格**，所有间距为 4 的倍数：

| 名称 | 值 | 用途 |
|------|------|------|
| xs | 4px | 图标与文字间距 |
| sm | 8px | 表单项内间距、紧凑型列表 |
| md | 12px | 表格单元格内边距 |
| base | 16px | 卡片内边距、区块间距 |
| lg | 20px | 页面内容区域内边距 |
| xl | 24px | 大区块间距 |
| 2xl | 32px | 页面顶部留白 |

### 页面内容区标准内边距

```scss
.page-container {
  padding: 20px;
}

.card-block {
  padding: 20px;
  margin-bottom: 16px;
}
```

| 元素 | 圆角 | 说明 |
|------|------|------|

| 按钮 | 4px | 保持一致 |

## 6. 阴影规范

| 层级 | 阴影 | 用途 |
|------|------|------|
| 无阴影 | none | 输入框、按钮 |
| 浅阴影 | `0 2px 12px 0 rgba(0,0,0,0.06)` | 卡片 |
| 中阴影 | `0 4px 16px 0 rgba(0,0,0,0.08)` | 对话框、下拉菜单 |
| 深阴影 | `0 8px 24px 0 rgba(0,0,0,0.12)` | 拖拽元素、浮层 |

> 阴影仅用于区分层级，不滥用。卡片在白底上可不加阴影，用边框 `1px solid #EBEEF5` 替代。

## 7. 组件使用规范

### 7.1 表单

- 使用 `el-form` + `el-form-item`，label-position 为 `right`。
- label-width 统一为 `100px`（根据实际字段长度微调）。
- 必填项用红色星号标识，不额外加 "(必填)" 文字。
- 输入框宽度：文本输入 `width: 100%`（在 form-item 内自适应），下拉选择 `width: 100%`。
- 表单底部操作按钮居右对齐。

```vue
<el-form :model="form" :rules="rules" label-width="100px">
  <el-form-item label="配件名称" prop="name">
    <el-input v-model="form.name" placeholder="请输入配件名称" />
  </el-form-item>
</el-form>
```

### 7.2 表格

- 使用 `el-table` + `el-table-column`。
- 斑马纹：`stripe` 属性开启。
- 边框：`border` 属性开启。
- 表头背景色：使用 Element Plus 默认灰色表头。
- 操作列固定在右侧：`fixed="right"`。
- 操作按钮使用 `el-button` 的 `link` 类型（文字按钮）。
- 分页使用 `el-pagination`，居右显示。

```vue
<el-table :data="list" stripe border>
  <el-table-column prop="barcode" label="条码" width="180" />
  <el-table-column prop="name" label="配件名称" />
  <el-table-column prop="categoryName" label="分类" width="120" />
  <el-table-column prop="createTime" label="入库时间" width="180" />
  <el-table-column label="操作" width="150" fixed="right">
    <template #default="{ row }">
      <el-button link type="primary" @click="handleEdit(row)">编辑</el-button>
      <el-button link type="danger" @click="handleDelete(row)">删除</el-button>
    </template>
  </el-table-column>
</el-table>

<div class="pagination-wrapper">
  <el-pagination
    v-model:current-page="pageNum"
    v-model:page-size="pageSize"
    :total="total"
    :page-sizes="[10, 20, 50]"
    layout="total, sizes, prev, pager, next, jumper"
  />
</div>
```

### 7.3 按钮

| 场景 | 类型 | 示例 |
|------|------|------|
| 主操作 | `type="primary"` | 提交、入库、领用 |
| 次要操作 | `type="default"` | 取消、重置 |
| 危险操作 | `type="danger"` | 删除（需二次确认） |
| 文字链接 | `link` | 表格内操作 |
| 图标按钮 | `icon` + `circle` | 收藏、刷新 |

- 主按钮使用 `plain` 属性的概率要低，大面积使用 `primary` 实心按钮。
- 按钮高度统一使用默认 `32px`。
- 页面主要操作按钮放在页面右上角或表单底部。

### 7.4 对话框

- 使用 `el-dialog`。
- 宽度：表单类对话框 `width="500px"`，详情类 `width="600px"`。
- 标题简洁，动词开头：新增配件、编辑师傅、确认删除。
- 底部按钮：取消 + 确定（主色）。
- 点击遮罩层不关闭（`:close-on-click-modal="false"`），防止误操作。

### 7.5 消息提示

- 成功：`ElMessage.success('入库成功')`
- 失败：`ElMessage.error('条码不能为空')`
- 警告：`ElMessage.warning('库存不足')`
- 确认删除：`ElMessageBox.confirm('确认删除该师傅？', '提示', { type: 'warning' })`
- 消息保持简短，不超过 20 字。

### 7.6 面包屑

- 使用 `el-breadcrumb`，显示当前页面路径。
- 格式：首页 > 模块名 > 页面名。
- 首页可点击跳转，当前页不可点击。

```vue

  <div class="page-container">
    <!-- 页面标题栏 -->

    <el-card class="form-card">
      <!-- 表单内容 -->

  color: #303133;

  // el-card 自带 padding
```

```
│  [返回]  标题  [操作]   │
├────────────────────────┤
│                        │
│      页面内容区域       │

│                        │
```

- 内容区使用 Vant 的 `van-cell-group` 和 `van-cell` 组织表单。
- 列表使用 `van-list` 实现下拉加载。

## 9. 交互规范

### 9.1 加载状态

- 按钮提交时显示 loading 状态：`:loading="loading"`
- 表格数据加载时显示骨架屏或 `v-loading` 指令
- 页面首次加载显示全屏 loading

### 9.2 空状态

- 列表无数据时显示空状态插图 + "暂无数据" 文字
- 使用 Element Plus 的 `el-empty` 组件

### 9.3 操作反馈

- 表单提交成功 → `ElMessage.success` + 重置表单或跳转
- 删除操作 → `ElMessageBox.confirm` 二次确认
- 扫码成功 → 短暂提示 + 自动填入条码 + 加载配件信息
- 扫码失败 → 提示"未识别到条码，请重试或手动输入"

### 9.4 表单校验

- 实时校验：`trigger: 'blur'`（输入框）/ `trigger: 'change'`（选择器）
- 提交前全量校验：`formRef.validate()`
- 校验错误信息显示在表单项下方（Element Plus 默认行为）

## 10. 图标使用规范

- 使用 Element Plus 内置图标（`@element-plus/icons-vue`）。
- 菜单图标：每个一级菜单配置一个语义化图标。
- 操作图标：配合文字使用，不单独使用图标（降低认知成本）。

| 模块 | 图标 |
|------|------|
| 首页 | `HomeFilled` |
| 配件入库 | `Download` |
| 配件领用 | `Upload` |
| 配件归还 | `RefreshLeft` |
| 配件售卖 | `ShoppingCart` |
| 总库存 | `Box` |
| 师傅管理 | `User` |
| 分类管理 | `Menu` |
| 操作日志 | `Document` |
| 条码追溯 | `Search` |

## 11. 响应式规则（PC 端）

| 断点 | 宽度 | 布局调整 |
|------|------|---------|
| 桌面 | ≥ 1200px | 侧边栏展开，内容区自适应 |
| 小桌面 | 992px - 1199px | 侧边栏折叠为图标模式 |
| 平板 | 768px - 991px | 侧边栏折叠，内容区全宽 |
| 手机 | < 768px | 引导用户使用 H5 端 |
